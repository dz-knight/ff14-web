# FF14 物价百科 Web

纯静态网页版本，支持中文搜索、国服价格查询和国服 Wiki 词条直达。

## 主要功能

- 纯静态部署，无需自建后端
- 本地双语映射表搜索
- 国服 Universalis 价格查询
- `全部 / HQ / 非 HQ` 价格查看
- 按国服大区筛选市场价格
- NPC 商店售价与精确坐标展示
- 国服 Wiki 词条直达
- 主题颜色调节
